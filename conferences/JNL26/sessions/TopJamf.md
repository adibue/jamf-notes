# Top Jamf: Tips & Tricks

_by **Jamfineers**_

## Jamf Extender

A browser extension to add functionality to your Jamf Pro UI, like setting a bar color to distinguish different instances.

It even offers things like a built-in JSS MUT - or a privilege picker for API roles 🔥

Where? [Here!](https://github.com/Jamf-Concepts/Jamf-Extender)

## 27 Betas

_"Got an upgrade plan for these?"_

Enable Beta updates quickly using _Blueprints_ and a generated _Apple Seed_ token.
What about making this available upon request or with _Self Service_ for anyone interested? 🤘

## DDM Explorer

_"If you love reading through json files, this is not for you!"_

[**DDM Explorer**](https://github.com/Jamf-Concepts/ddm-explorer) helps generating custom declarations for using with _DDM/Blueprints_ by offering an easy-to-use interface comparable to ProfileCreator.

Upgrade your legacy profiles today with DDM Explorer! 🚀

## Jamf Routines

_"It's a no-code automations automation tool!"_

Wanna automate things but don't know how?
Wanna get notified in your favourite messenger, when things happen?
Got no clue where to start?

Then [Jamf Routines](https://www.jamfroutines.com/sc/home.aspx) is here to help!

It is a simple website offering tons of templates to get you started on automating things! 🤖
